CREA IMAGEN — Proyecto completo actualizado (23 de octubre de 2026)

La MISMA versión funciona en Visual Studio Code y en GitHub Pages.

PARA VS CODE:
1. Extrae todo el ZIP.
2. Abre la carpeta extraída desde Archivo > Abrir carpeta.
3. Haz clic derecho en index.html > Open with Live Server.

PARA ACTUALIZAR GITHUB:
1. Ve al repositorio Creaimagen26/creaimagen.
2. Code > Add file > Upload files.
3. Sube TODOS los archivos y la carpeta assets que están DENTRO de la carpeta del proyecto; NO subas el ZIP ni la carpeta contenedora.
4. Comprueba que index.html y styles.css queden en la raíz, y assets/ contenga las imágenes.
5. Guarda con Commit changes en main.
6. Una vez publicado, usa Ctrl+Shift+R en el navegador para evitar la caché.

Correcciones:
- Título de servicios: tipografía DM Sans, mejor espaciado; ya no queda comprimido.
- Imágenes de servicios: se muestran completas sin cortes, con fondo difuminado que rellena el marco.
- Logo: archivo PNG oficial suministrado por Crea Imagen, sin volver a comprimir ni recortar.
- Conserva los botones, catálogo, animación de cambio de imágenes y datos de contacto.

La ubicación es un enlace de búsqueda general mientras no se proporcione una ficha exacta de Google Maps.
