CREA IMAGEN - WEB PARA GITHUB PAGES Y VS CODE

1. Entra a github.com/Creaimagen26/creaimagen
2. Asegura que estás en main, pestaña Code.
3. Add file -> Upload files.
4. Sube index.html y catalogo-crea-imagen.pdf (ambos al nivel principal, NO una carpeta).
5. Commit changes en main.
6. Comprueba en Settings -> Pages que diga Deploy from a branch, main, /(root).
7. Espera el despliegue. Luego recarga con Ctrl+Shift+R en la web.

IMPORTANTE: Todos los logos, ilustraciones, CSS y JavaScript están DENTRO de index.html.
No necesitas subir la carpeta assets: así se evitan rutas de imágenes rotas.
Solo el catálogo PDF es externo y se incluye.

Para VS Code: abre esta carpeta y ejecuta index.html con Live Server.

El logo conserva los bytes originales del archivo suministrado.
